## 1. 为什么必须用成组作品

| 来源 | 能得到的 | 得不到的 |
|---|---|---|
| 单篇论文 / 单篇博客 | 一个案例 | 方法（可能只是这篇的特例） |
| 8+ 篇成组作品 | **重复结构 = 方法内核** | — |

**判断方法**：如果你只能说出"他做了 A、B、C"，那是案例集。只有当你发现"A、B、C 在他几乎每篇里都出现，顺序也稳定"时，你才拿到了方法。

**样本量建议**：≥ 8 篇。少于 8 篇时，明确标注"样本有限，内核判定置信度低"。

## 2. 反推四步

### 步骤 1：铺开
列出全部作品，一行一篇，含年份、期刊/状态、来源级别。

### 步骤 2：拆要素
把每篇拆成**同一组**要素。要素集必须与 skill 类型匹配（见下节），且在开始拆之前就定好——中途改要素集会让已有拆分作废。

### 步骤 3：找重复
统计每个要素的出现频次。

```
要素 X：出现 11/13 篇 → 内核候选
要素 Y：出现 9/13 篇  → 内核候选
要素 Z：出现 4/13 篇  → 特例，不是方法
要素 W：出现 1/13 篇  → 这篇的偶然选择
```

### 步骤 4：找差异
**只出现在少数篇里的要素，往往是最有价值的边界信息。** 例如：

- 只有那篇做预测的论文报告了"尾部误差" → 说明这是该类工作的加分项，不是通用要求
- 只有两篇用了某种识别设计 → 说明这是条件性手法，不能写成默认步骤

把差异写进"边界条件"或"进阶选项"，而不是混进主流程。

## 3. 按 skill 类型的拆解维度

### 学术研究方法

| 要素 | 检查什么 |
|---|---|
| 经典问题 | 是否有公认的重要性论证 |
| 数据通道 | 是否有此前未被开采的信息源 |
| 外生变化 | 是否有**可定位日期**的冲击 |
| 机制 | 是理论先行还是加控制变量 |
| 价值终点 | 是否落到可量化的经济量 |
| 测量处理 | 因变量若是度量，是否处理了漂移 |
| 边界 | 是否报告了适用域而非只有均值 |

### 工程实践

| 要素 | 检查什么 |
|---|---|
| 输入 | 接什么 |
| 关键决策 | 在哪里做了取舍 |
| 输出 | 交付物形态 |
| 失败模式 | 出过什么问题、怎么兜住 |
| 度量 | 怎么判断成功 |
| 边界 | 什么情况下不适用 |

### 写作/表达方法

| 要素 | 检查什么 |
|---|---|
| 开头策略 | 第一句/第一段做什么 |
| 组织方式 | 按时间、按观点、按问题 |
| 转折手法 | 如何从"已知"转到"缺口" |
| 证据密度 | 每段几个数据点 |
| 收尾 | 如何收束与限定 |
| 禁用项 | 从不使用的表达 |

### 产品/商业方法

| 要素 | 检查什么 |
|---|---|
| 用户痛点 | 解决的具体是谁的什么问题 |
| 解法形态 | 产品形态与切入角度 |
| 定价 | 收费方式与隐含假设 |
| 分发 | 增长依赖什么渠道 |
| 壁垒 | 什么阻止复制 |

## 4. 门槛与反例

### 内核门槛

| 出现频次 | 判定 | 处理 |
|---|---|---|
| ≥ 60% | 方法内核 | 写进主流程，设为默认步骤 |
| 30–60% | 常见手法 | 写进主流程但标注"视情况" |
| 10–30% | 进阶选项 | 单独成节，标注"进阶" |
| < 10% | 特例 | 只在案例册提及，不进方法 |

### 反例：伪内核

| 表面现象 | 实际含义 |
|---|---|
| 所有论文标题都长 | **不是方法**，是发表时的格式化 |
| 所有论文都发在同一领域 | 不是方法，是研究领域 |
| 都用了回归 | 不是方法，这是学科默认 |
| 都先写了引言 | 不是方法，这是论文格式 |

**检验**：这个"内核"如果换个人做，还成立吗？如果换成任何研究者都成立，那它是学科惯例，不是这个人的方法。

## 5. 从要素到规则

要素表不是终点。要把重复结构翻译成**可执行的规则**。

### 翻译步骤

```
观察到的重复结构：
  几乎每篇都用某种有明确生效日期的冲击做识别

翻译成规则：
  "优先寻找有明确生效日期、处理分配不由主体自选的外生变化；
   找到后先做三项诊断（平行趋势 / 安慰剂 / 处理前平衡）再做主回归。"

补上判据：
  "如果三项诊断有两项失败，不要用因果动词，降级为关联性证据。"
```

**规则的三要素**：

1. **做什么**（可执行的动作）
2. **为什么**（依据，否则模型在没覆盖的情况里不会做对）
3. **判据**（什么算通过）

缺第 3 项的规则无法自我检查，缺第 2 项的规则无法外推。

## 6. 命名纪律

### 坏命名 vs 好命名

| 坏 | 为什么坏 | 好 |
|---|---|---|
| 重视数据质量 | 无法检查 | 因变量若是度量，必须做人类基准验证并报告误差分解 |
| 注重理论机制 | 无法检查 | 机制必须事前立成可证伪的预测，异质性是验证而非发现 |
| 注意因果识别 | 无法检查 | 优先用有明确日期的外生变化；用控制变量代替外生变化不算识别 |
| 关注创新 | 同上 | 贡献必须表述为"改变了哪条已有结论"，而非"首次应用" |

### 检验

> 把这条规则念给同事听，他能判断某篇论文**违反了**它吗？
>
> 不能 → 这不是规则，是口号。
