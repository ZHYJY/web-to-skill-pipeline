# 抽取简报（Extraction Brief）

> **开工前写。** 不写简报的最后通常会产出一份"谁都能写"的泛泛方法论。
> 填写要求：每格一句话，不得留"待定"。

---

## 1. 任务

| 项 | 内容 |
|---|---|
| 来源 | URL / 文件 / 页面清单（由用户提供，例如官网页面 + Google Scholar 个人主页） |
| 要产出的 skill 名称 | |
| 要解决的真实问题 | （用户会拿它做什么） |

---

## 2. 提炼什么方法

只写**一类**。一次提炼多类会得到一份互相干扰的清单。

| 项 | 内容 |
|---|---|
| 方法类型 | 选题 / 实验设计 / 写作 / 工程架构 / 产品 / 数据分析 |
| 具体到 | |
| 判据 | （把方法变成**可检查**的结构要素，不是形容词） |

---

## 3. 不提炼什么

明确排除，避免把无关信息混进来：

- 履历与荣誉：
- 资源条件（数据、团队、平台、机构）：
- 时代背景：
- 其他：
