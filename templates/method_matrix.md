## 4. 伪内核剔除

| 表面现象 | 是否伪内核 | 判定理由 |
|---|---|---|
| | | 换成任何人都成立 = 学科惯例 |
| | | 与主题绑定 = 研究领域而非方法 |

**检验**：这个内核换个人做还成立吗？成立 → 不是这个人的方法。

---

## 5. 差异项（边界条件）

| 要素 | 只出现在 | 可能的原因 |
|---|---|---|
| | | 某类问题的特有要求（加分项，非通用） |
| | | 条件性手法（不可写成默认步骤） |

> 差异项归入"边界条件/进阶选项"，**不混进主流程**。
